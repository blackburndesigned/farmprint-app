# Security Policy

## Supported versions

FarmPrint is in early release. Only the newest version gets security fixes, so please update before reporting. Installed copies check for updates on their own.

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately instead:

1. Go to [Report a vulnerability](https://github.com/blackburndesigned/farmprint-app/security/advisories/new).
2. Describe what you found, how to reproduce it, and which version and operating system you used.

Only the maintainers can see the report. You can expect a first reply within a few days. Once a fix is released, we'll publish an advisory and credit you unless you'd rather stay anonymous.

## What counts

Good examples are anything that lets a file, a web page, or another program read or change a user's data without their say, run code on their computer, or get at a connected shop's sign-in. Problems in a third-party service you connect to (your own shop server, Bambu Studio) belong with that service.
